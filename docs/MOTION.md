# Interaction and motion

SiteMotion is a small client enhancement mounted in the existing root layout. IntersectionObserver reveals editorial sections, workspace cards and panels once, using native Web Animations. A child-list observer registers streamed/new content. Route changes and preference changes cancel active animations and disconnect observers; there is no scroll handler, perpetual animation loop or new dependency. No content is hidden before JavaScript or made dependent on animation.

CSS adds pointer-only card lifts/image zoom, button press feedback, selected-option styling, estimate-change feedback and a FAQ toggle indicator. Touch users retain native controls without hover-dependent actions. prefers-reduced-motion disables animation/transitions and skips the reveal observer; changing the preference also cancels active reveals. Keyboard focus remains visible.

Verified in installed Chrome: accessory hover scale, native FAQ expansion, no running animations under reduced motion, configurator size selection updating the estimate to $449, no browser errors, and no configurator horizontal overflow at 320/390/768/1440 px. Lint (existing logout warning), TypeScript, 132 unit tests and production build passed. Real mobile devices, authenticated workspace animation and full backend/browser regression were not exercised in this pass. No database, authentication or route behavior changes.

## Lightweight depth and optional hero 3D

The homepage hero reuses the existing parameterized desk through a dynamically imported SceneCanvas, mounted only after Explore in 3D. Low quality caps DPR at 1, uses 512px decoded wood maps and disables shadow passes. Demand rendering stops while idle; visibility observers suspend rendering offscreen/in a hidden tab. Closing the preview unmounts its Canvas. No autoplay orbit, extra 3D library or global WebGL background was added.

Hero finish choices are temporary until Continue this design explicitly writes the validated product-only local draft and navigates to the configurator. Storage failures stay visible and do not silently discard the choice. Front/reset controls support keyboard exploration; wheel zoom is disabled in the hero so page scrolling still works. Existing configurator wheel behavior stays enabled by default. Unsupported WebGL, renderer errors and a 20-second startup timeout return to the supplied poster with an honest status.

Fine pointers gently tilt accessory/material/design previews using bounded CSS variables, one scheduled frame per pointer event and complete listener/frame cleanup. Touch skips pointer tilt. Native view-timeline support adds a restrained perspective unfold to accessories and the specification diagram, with normal content as the unsupported-browser fallback. Reduced motion cancels active reveals, clears tilt variables and disables scroll animations.

Verified in installed desktop Chrome/software WebGL: zero initial canvases, one after activation, finish selection, front camera control, wheel scrolling over the canvas, Walnut product draft handoff, and zero canvases after Close 3D. Simulated no-WebGL returns to poster. No overflow at 320/390/768/1024/1440 px; pointer tilt resets and running animations drop to zero on reduced-motion changes. Browser page errors: zero. TypeScript, production build and 132 unit tests passed; lint retains only the existing logout-navigation warning. Desktop/mobile preview screenshots were inspected temporarily; no new generated imagery or evidence screenshot set was added. Hardware mobile performance and the full backend integration suite were not rerun.
