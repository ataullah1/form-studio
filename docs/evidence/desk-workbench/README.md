# Desk design workbench — 2026-10-21

The existing desk builder now supports reversible starting setups, an optional room context and tools for inspecting, comparing and exporting the actual model. This extends the current catalogue product; it is not a freeform CAD editor or manufacturing specification.

## Implemented

- Three editable starting setups, selected-state feedback, a bounded fifty-edit history, undo/redo and Ctrl/Cmd-Z, Shift-Z/Y shortcuts. Text inputs, contact fields and unrelated navigation retain their native editing behavior. Only the current valid product configuration enters the existing local draft, share, estimate and quote paths. Undo history and the single comparison reference are in-memory and clear on reload.
- Studio/Room settings, three room floor colours, original wall/baseboard geometry and a matte floor receiving existing cached directional shadows. Frame material is less metallic. Balanced/Low, demand rendering, texture resource ownership, visibility pause, WebGL fallback and context teardown remain available; no external model, HDRI, dependency or image download was added.
- Optional width/depth/height line guides and readable DOM labels anchored to the real model dimensions; new top and rear camera views stay within the existing safe orbit/zoom envelope. Look-closer controls explain the tabletop, frame and accessories. The lamp can be switched independently of day/night using its button or clicking its 3D geometry.
- Expanded inline preview, reversible A/B comparison of a retained configuration against the current design, and PNG export of the actual WebGL scene. Comparison never changes current inputs, quotes or save payloads. Export renders and captures once without a permanent preserved drawing buffer; HTML dimension labels are explicitly excluded.
- Save/share/quote/account contracts and the existing three catalogue sizes, three finishes, two frame colours and three accessories are retained. Room, lighting, dimensions, camera and lamp power are view preferences, not saved product options. Accessory positions remain the existing fixed validated placement.
